# [Issue #154 → Issue #154] Sadstore integration tests still use `minio/minio:latest` testcontainer

`#154` substituted RustFS for MinIO in the production deployment surface. The TODO 2 commit landed the source-side and manifest env-var renames (`MINIO_*` → `OBJECTS_*`) but kept the three sadstore integration test files (`services/sadstore/tests/sad_builder_tests.rs`, `tests/identity_builder_tests.rs`, `tests/integration_tests.rs`) using `GenericImage::new("minio/minio", "latest")` as their black-box S3 fixture, on the rationale that the `aws-sdk-s3` client doesn't differentiate at the wire and the MinIO testcontainer's stderr-message readiness signal (`WaitFor::message_on_stderr("API:")`) didn't have a verified RustFS analog.

**Resolution.** TODO 4's wider doc sweep added forbidden-terminology patterns banning `MinIO` / `MINIO_*` repo-wide, which forced the test fixtures to migrate too. All three test files now spin up `rustfs/rustfs:latest` with `WaitFor::seconds(5)` (a generous fixed wait covering RustFS's startup; the testcontainers 0.27 `WaitFor::Http` variant is feature-gated and would have required adding the `http_wait` feature to the dep). Container env vars switched from `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` + `with_cmd(["server", "/data"])` to `RUSTFS_ACCESS_KEY` / `RUSTFS_SECRET_KEY` / `RUSTFS_VOLUMES=/data` / `RUSTFS_ADDRESS=0.0.0.0:9000` / `RUSTFS_CONSOLE_ADDRESS=0.0.0.0:9001` (env-driven startup; no command override needed). Local variables and the `_minio` struct field on `SharedHarness` renamed to `_objects` / `objects_*`. The `OBJECTS_ACCESS_KEY` / `OBJECTS_SECRET_KEY` env-var values that the kels Rust source reads switched from `"minioadmin"` to `"rustfsadmin"` to match RustFS's defaults.

**Future work.** If `WaitFor::seconds(5)` proves flaky on slower CI machines, promote to `WaitFor::Http` against `/health` on port 9000 by adding the `http_wait` feature to the testcontainers dep — RustFS's docker-compose healthcheck is exactly that endpoint. The fixed wait was chosen over the dep-feature bump for diff minimality; revisit when CI signal supports the call.
